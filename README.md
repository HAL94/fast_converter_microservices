# fast_converter_microservices

A sample microservices app with UV workspaces to build a video to mp3 converter system, for learning purposes.

# The objective

I wanted to try microservices, this project is based on the video tutorial by (`kantan coding`)[https://www.youtube.com/watch?v=hmkF77F9TLw], however I did not follow the tutorial completely, I surmised the requriements as follows:

`A user uploads a video, and the system will convert the video to MP3 format, and notify the user by email and provide a download link for the file as an MP3 file.`

# Components
- **Gateway**: Receive user requersts
- **Auth**
- **RabbitMQ**
- **Video-to-MP3**
- **Notification**
